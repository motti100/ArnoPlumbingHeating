# Arno Plumbing & Heating — Website

Professional website for Arno Plumbing & Heating. Single HTML file, zero dependencies, hosts free on GitHub Pages.

## 🚀 Deploy to GitHub Pages (5 minutes)

1. **Create a new GitHub repo** — go to github.com → New Repository → name it `arno-plumbing` → Public → Create

2. **Upload the file** — drag `index.html` into the repo file area and commit

3. **Enable GitHub Pages** — Settings → Pages → Source: "Deploy from branch" → Branch: `main` → `/root` → Save

4. **Your site is live at** → `https://[your-username].github.io/arno-plumbing`
